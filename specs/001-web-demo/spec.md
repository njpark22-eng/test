# 기능 명세: 웹 데모 (Vercel 배포)

**기능 브랜치**: `001-web-demo`
**작성일**: 2026-11-13
**상태**: 초안
**입력**: Vercel 빌드가 `PYTHON_ENTRYPOINT_NOT_FOUND`로 실패했다. CLI/tkinter 도구인 `vibe_agent.py`의 판정 결과를 웹 화면으로 보여 주는 읽기 전용 데모를 만든다. 원칙은 `.specify/memory/constitution.md`, 상세 규칙은 `CLAUDE.md`의 '웹 데모' 절을 따른다.

## 사용자 시나리오와 테스트 *(필수)*

### 사용자 스토리 1 - 5채널 판정 결과 보기 (우선순위: P1)

시연 참석자나 담당자가 URL을 열면 첫 화면에서 CH1~CH5의 판정과 근거 수치를 본다.

**우선순위 이유**: 이 데모의 목적이다. 이것만 있어도 배포 실패가 해결되고 시연이 가능하다.

**독립 테스트**: 배포(또는 `uv run uvicorn api.index:app`) 후 첫 화면과 `/api/analyze`를 열어 5채널 판정이 기대값과 같은지 확인한다.

**인수 시나리오**:

1. **조건** 저장소에 가상 데이터 `data/CH1~CH5.xlsx`가 있다, **동작** 첫 화면을 연다, **결과** 채널별 rpm, 최대 피크 RMS(기준 4.5 mm/s), 2X/1X, BPFO/1X(볼 개수 1은 `-`), 결함 진단이 표로 보인다.
2. **조건** 기본 데이터, **동작** 판정을 본다, **결과** CH1 재계측 권장 / CH2 정상 / CH3 베어링 점검 요망 / CH4 발란싱 요망 / CH5 정렬 요망이다.
3. **조건** 화면을 연다, **동작** 3초 안에 훑는다, **결과** 판정명과 근거 수치를 읽을 수 있고 '가상 데이터, 규칙 기반 판정' 표시가 보인다.

---

### 사용자 스토리 2 - 채널별 FFT 스펙트럼 확인 (우선순위: P2)

사용자가 채널별 FFT 그래프에서 판정 근거(1X, 2X, 베어링 피크, 허용기준선)를 눈으로 확인한다.

**우선순위 이유**: 판정 표의 수치가 그래프와 맞는지 사람이 대조하는 지점이다(RETRO의 '사람이 본 곳').

**독립 테스트**: 그래프의 1X/2X/BPFO 세로줄 위치가 `rpm/60`, `2 x 1X`, `1X/2 x 0.8 x 볼 개수`와 같은지 확인한다.

**인수 시나리오**:

1. **조건** CH3(볼 9개), **동작** 그래프를 본다, **결과** 1X, 2X, BPFO 세로줄이 보이고 BPFO 피크를 짚을 수 있다.
2. **조건** CH1(볼 1개), **동작** 그래프를 본다, **결과** BPFO 세로줄이 없고 재계측 안내가 보인다.
3. **조건** 모든 채널, **동작** 그래프를 본다, **결과** 허용기준선(4.5 mm/s)과 단위(mm/s RMS)가 표시된다.

---

### 사용자 스토리 3 - 판정 규칙 확인과 다른 화면 환경 (우선순위: P3)

사용자가 판정 규칙 문구를 읽고, 휴대폰이나 다크 모드에서도 화면을 본다.

**우선순위 이유**: 설명 가능성과 시연 환경(프로젝터, 휴대폰) 대응이다.

**독립 테스트**: 휴대폰 폭과 다크 모드에서 화면을 열어 가로 스크롤과 깨짐이 없는지, 규칙 문구가 `RULES`와 같은지 확인한다.

**인수 시나리오**:

1. **조건** 화면 하단, **동작** 규칙 영역을 본다, **결과** `RULES` 원문이 그대로 보인다(별도 하드코딩 없음).
2. **조건** 휴대폰 폭, **동작** 연다, **결과** 가로 스크롤 없이 표가 카드로 접혀 보인다.
3. **조건** Noto Sans KR 로딩 실패, **동작** 연다, **결과** 시스템 폰트로 대체되어도 레이아웃이 유지된다.

---

### 예외 상황

- `data/CH1~CH5.xlsx`가 배포본에 없으면 오류 상태 코드와 원인·조치를 한 줄로 알린다(예: "data 폴더에 CH1~CH5 파일이 없습니다. `--make-data`로 생성하세요").
- 일부 채널만 있으면 있는 채널만 분석하지 않고 같은 오류로 알린다. 현재 `load_signals`는 5개가 모두 있어야 로드한다.
- 경계값 근처(RMS 4.5, 2X/1X 0.5, BPFO/1X 0.7, 저주파 20)는 `rule_verdict` 결과를 그대로 보여 주고 화면에서 따로 반올림하지 않는다.
- 데이터를 업로드하거나 수정하려는 요청은 지원하지 않는다(엔드포인트 없음).

## 요구사항 *(필수)*

### 기능 요구사항

- **FR-001**: 시스템은 `vibe_agent`의 `spectrum`, `analyze_signal`, `rule_verdict`, `RULES`를 import해서 판정하며 판정·FFT 로직을 다시 구현해서는 안 된다.
- **FR-002**: 시스템은 저장소에 포함된 가상 데이터 `data/CH1~CH5.xlsx`를 읽기 전용으로만 열어야 한다. 업로드, 저장, 수정, 덮어쓰기를 제공하지 않으며 `result-N`, `review-N.json`을 만들지 않는다.
- **FR-003**: 시스템은 규칙 기반 판정만 제공해야 한다. Claude API를 호출하지 않고 `ANTHROPIC_API_KEY`를 요구하지 않는다.
- **FR-004**: `GET /`은 판정 표와 FFT 그래프, `RULES` 원문, '가상 데이터, 규칙 기반 판정' 표시를 가진 한 페이지를 돌려줘야 한다.
- **FR-005**: `GET /api/analyze`는 채널별 `analyze_signal` 결과, `rule_verdict` 판정, 0~600 Hz 스펙트럼 배열을 JSON으로 돌려줘야 한다.
- **FR-006**: 그래프는 1X/2X 세로줄을 모든 채널에, BPFO 세로줄을 볼 개수 2 이상인 채널에만 표시하고 허용기준선을 표시해야 한다.
- **FR-007**: 색조는 흰 배경, 파랑 한 가지(`#0C4CA3`), 회색 계열로 제한해야 한다. 판정 색만 예외로 의미로 고정하고(정상=초록, 재계측/베어링=주황, 발란싱/정렬=빨강, 판정 배지·셀에만 사용) 판정명 글자와 기호를 항상 같이 쓴다. 참고 이미지의 로고·회사명·상표는 쓰지 않는다. 숫자는 단위를 표기한다.
- **FR-008**: 화면은 라이트/다크와 휴대폰 폭을 지원하고 폰트는 Noto Sans KR(대체 폰트 포함)을 쓴다.
- **FR-009**: 화면 문구는 SPEC의 판정명 표기를 그대로 쓰고 constitution의 slop 방지 규칙(문구·디자인)을 따라야 한다.
- **FR-010**: 배포는 진입점 `api/index.py`, `vercel.json`(리전 `icn1`, 번들 `vibe_agent.py`와 `data/*.xlsx`), `.vercelignore`(발표자료, 검수 파일, `.venv`, `tests`, `.claude` 제외)로 구성하고 웹 의존성은 `numpy`, `openpyxl`, `fastapi`로 제한한다. 의존성을 바꾸면 `uv.lock`도 갱신한다.
- **FR-011**: `tests/`에 `/api/analyze`가 5채널 기대 판정을 돌려주는지, `GET /`이 200을 돌려주는지, 데이터가 없을 때 오류를 돌려주는지 확인하는 테스트를 추가한다.

### 주요 개체

- **채널(Channel)**: CH1~CH5 중 하나. rpm, 볼 개수, 시간 신호를 가진다.
- **분석 결과(Analysis)**: `analyze_signal`이 만드는 특징량(최대 피크 RMS, 1X/2X/BPFO RMS, 비율, 저주파 노이즈)과 `rule_verdict` 판정.
- **스펙트럼(Spectrum)**: 주파수(Hz)와 RMS 진폭(mm/s) 배열. 화면용으로 0~600 Hz만 보낸다.

## 성공 기준 *(필수)*

### 측정 가능한 결과

- **SC-001**: Vercel 빌드가 성공하고 Production URL에서 5채널 판정이 기대값 5/5와 일치한다.
- **SC-002**: 첫 화면에서 판정명과 근거 수치(최대 피크 RMS, 2X/1X)가 채널 5개 모두에 표시된다(100%).
- **SC-003**: `uv run pytest`가 통과하고 웹 테스트가 포함된다. 입력 엑셀의 해시가 배포 전후로 같다.
- **SC-004**: 휴대폰 폭과 다크 모드에서 가로 스크롤과 깨짐이 없다.
- **SC-005**: 화면 텍스트가 문구 체크리스트(수식어, 근거 없는 주장, 번역투)와 디자인 체크리스트(그라디언트, 이모지 아이콘, 가짜 지표) 위반 0건이다.

## 가정

- 대상은 시연 참석자와 담당자 1~2명이며 데이터는 가상 신호뿐이다(실사용 전환은 범위 밖).
- 인증, 업로드, 외부 저장소(Vercel Blob), 설비별 기준값(ISO 등급)은 이번 범위가 아니며, 필요해지면 별도 spec(`002-...`)으로 명세한다.
- 규칙 기반 판정만 쓰므로 환경변수가 필요 없다.
- Vercel 플랜별 함수 크기·실행 시간 제한은 배포 시 확인하며, 현재 데이터는 5채널 x 2초(10,240 샘플)로 작다.
- 외부 slop 방지 스킬은 아직 설치하지 않았고, 설치 전에는 체크리스트로 점검한다.
